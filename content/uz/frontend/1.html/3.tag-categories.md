## Savol

HTML teglari qanday tasniflanadi: blok elementlari satr elementlaridan nimasi bilan farq qiladi, void-elementlar nima va almashtiriladigan (replaced) va almashtirilmaydigan elementlar o'rtasida qanday farq bor?

## Qisqa javob

Asosiy bo'linish — **block** (butun kenglikni egallaydi, yangi qatordan boshlanadi) va **inline** (matn oqimida faqat zarur joyni egallaydi). Alohida holda yopuvchi tegi va mazmuni bo'lmagan **void-elementlar** (`<img>`, `<br>`, `<input>`) va mazmuni HTML/CSS dvigateli emas, balki tashqi resurs tomonidan render qilinadigan **replaced-elementlar** (`<img>`, `<video>`, `<iframe>`) ajratiladi.

## Batafsil javob

**Block va inline (standart holatda, CSS `display` orqali):**

- **Block-level** (`div`, `p`, `h1`–`h6`, `section`, `ul`) — yangi qatordan boshlanadi, ota elementning butun mavjud kengligini egallaydi, `width`/`height`/vertikal `margin`ni qabul qiladi.
- **Inline** (`span`, `a`, `strong`, `em`) — qator uzilishini yaratmaydi, kengligi/balandligi mazmun bilan belgilanadi, vertikal `margin`/`padding` qo'shni qatorlarga vizual ta'sir qilmaydi.
- **Inline-block** — HTML teglarining CSS standarti emas, balki `display` qiymati, gibrid: qatorda oqadi, lekin blok elementi kabi `width`/`height`ni qabul qiladi.

Muhim: bu tegning qat'iy xususiyati emas, balki brauzerning UA-uslubi bilan berilgan standart xatti-harakat — `display`ni CSS'da o'zgartirish mumkin.

**Void-elementlar (bo'sh elementlar):**

Mazmuni va yopuvchi tegi yo'q: `<img>`, `<br>`, `<hr>`, `<input>`, `<meta>`, `<link>`, `<area>`, `<col>`, `<embed>`, `<source>`, `<track>`, `<wbr>`. HTML5'da oxiridagi slesh (`<br />`) shart emas, lekin XHTML/XML-parserlar bilan mosligi uchun ruxsat etiladi.

**Replaced va non-replaced elementlar:**

- **Replaced** — brauzer mazmunni tashqi manbadan qo'yadi, va CSS ichiga "qarab" ko'ra olmaydi: `<img>`, `<video>`, `<audio>`, `<iframe>`, `<embed>`, qisman `<input>` va `<textarea>`. Ularning tashqi ko'rinishi odatiy CSS qoidalariga emas, balki resursning ichki renderchisiga bog'liq (masalan, `::before`/`::after` ularga qo'llanmaydi yoki cheklangan holda qo'llanadi).
- **Non-replaced** — mazmun HTML/CSS dvigatelining o'zi tomonidan bola tugunlaridan shakllantiriladi: `<p>`, `<div>`, `<span>` va qolgan teglarning ko'pchiligi.

Bu bo'linish CSS uchun muhim: replaced-elementlarda aniq `width`/`height` bo'lmaganda layout hisob-kitobiga ta'sir qiluvchi **intrinsic dimensions** (ichki o'lchamlar, masalan `<img>`da — rasmning asl o'lchami) mavjud.

## Misol

```html
<!-- block -->
<div>Blok element — o'z qatori, butun kenglik</div>

<!-- inline -->
<p>Matn <span>satr</span> va <a href="#">satr</a> elementi bilan</p>

<!-- void-elementlar: mazmuni va yopuvchi tegi yo'q -->
<img src="photo.jpg" alt="Rasm" />
<br />
<input type="text" name="username" />

<!-- replaced-element: tashqi dvigatel (rasm dekoderi) tomonidan render qilinadi -->
<img src="cat.png" alt="Mushuk" width="200" height="150" />
```

## Qo'shimcha savollar

* `display: inline-block` `display: inline` va `display: block`dan nimasi bilan farq qiladi?
* Nega `<textarea>` qisman replaced-element deb hisoblanadi?
* `<img>`da `width`/`height` yo'qligi CLS'ga (Cumulative Layout Shift) qanday ta'sir qiladi?
