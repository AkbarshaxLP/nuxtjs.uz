## Savol

`static`, `relative`, `absolute`, `fixed` va `sticky` bir-biridan nimasi bilan farq qiladi?

## Qisqa javob

`position` element hujjat oqimida qanday ishtirok etishini va `top/left/right/bottom` nimaga nisbatan hisoblanishini belgilaydi.

## Batafsil javob

- **`static`** (standart) — element odatiy oqimda, `top/left` ta'sir qilmaydi.
- **`relative`** — oqimda qoladi, lekin `top/left` orqali o'zining boshlang'ich pozitsiyasiga nisbatan siljishi mumkin. Shuningdek `absolute`ga ega farzandlar uchun koordinatalar tizimini yaratadi.
- **`absolute`** — oqimdan chiqadi, `position`i `static`dan farqli bo'lgan eng yaqin ajdodga (yoki bunday bo'lmasa `<html>`ga) nisbatan joylashadi.
- **`fixed`** — oqimdan chiqadi, ko'rish oynasi (viewport)ga nisbatan joylashadi va skroll paytida siljimaydi.
- **`sticky`** — `relative` va `fixed`ning gibridi: belgilangan chegaraga (`top: 0`) yetguncha `relative` kabi xatti-harakat qiladi, keyin esa ota doirasida `fixed` kabi "yopishib qoladi".

## Misol

```css
.dropdown {
  position: relative; /* menyu uchun langar */
}

.dropdown-menu {
  position: absolute;
  top: 100%;
  left: 0;
}

.header {
  position: sticky;
  top: 0;
}
```
